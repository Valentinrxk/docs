---

La **API pública de OCLÜ** te permite conectar tu clínica con sistemas externos: automatizá turnos, sincronizá pacientes, registrá gastos y leé tu agenda desde n8n, Make, Zapier o tu propio software.

## Autenticación

Generá tu **API key** desde tu panel (**Configuración → API Keys**). Se muestra una sola vez. Enviala en cada request:

```
Authorization: Bearer oclu_live_xxxxxxxxxxxxxxxxxxxx
```

Cada key tiene un permiso: **solo lectura** o **lectura y escritura**.

## Sede (Current-Org-Id)

Los endpoints de turnos, pacientes y gastos requieren el header `Current-Org-Id` con el ID de la sede. Consultá tus sedes en [`GET /me`](/api-reference/endpoint/get).

```
Current-Org-Id: 1
```

## A tener en cuenta

- **Hora local de la clínica:** las fechas/horas no son UTC. En turnos, fecha `DD-MM-YYYY` y hora `HH:MM`.
- **Sin datos clínicos:** la API expone agenda, turnos y datos de contacto. Nunca historia clínica.
- **Sin cobros:** la facturación y los cobros a pacientes no están disponibles en esta versión. Sí se pueden registrar gastos.
- **Rate limit:** 90 solicitudes por minuto por API key.
- **Auditoría:** toda actividad queda registrada.

## Verificá tu conexión

Probá `GET /me` con tu API key: te devuelve tu tenant, las sedes disponibles y los permisos de la key.
